Headless CMS backend for my personal developer portfolio, built with Sanity Studio and TypeScript.

→ Live site: [isahecam.dev](https://isahecam.dev)

## Overview

### Stack

- Sanity
- TypeScript
- Oxlint
- Oxfmt

### Featured

- Headless CMS workspace tailored for a developer portfolio
- i18n Content Fields: Multi-language support built directly into the schemas
- Ultra-fast linting and formatting powered by OXLint and OXfmt
- Clean, type-safe schema definitions
- Structured data management for projects, resume, and site metadata
